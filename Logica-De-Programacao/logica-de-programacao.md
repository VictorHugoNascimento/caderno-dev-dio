# O que é Lógica de Programação?

A **lógica de programação** é a organização estruturada do raciocínio para criar uma sequência de passos para encontrar uma solução para um problema computacional. É a base de todo o desenvolvimento de software, através dela você monta todo o "esqueleto" do seu programa, independente da linguagem que será utilizada.

## Conceitos Básicos

**Algoritmos:**
Algoritmo é uma sequência de passos para resolver um problema. Pense em fazer um bolo, você precisa seguir uma sequência para conseguir fazer o bolo.

O problema: Quais passos seguir para conseguirmos fazer o bolo?

O Algoritmo é a sequência lógica que deve ser seguida para conseguirmos resolver o problema.

O passo a passo para fazer o bolo seria:<br>
1 - Pegar uma bacia. <br>
2 - Adicionar a farinha. <br>
3 - Adicionar ovos. <br>
4 - Adicionar manteiga. <br>
5 - Adicionar leite. <br>
6 - Adicionar fermento. <br>
7 - Misturar todos os ingredientes. <br>
8 - Ligar o forno para deixá-lo preaquecido. <br>
9 - Passar a massa para uma forma que possa ser levado ao forno. <br>
10 - Colocar a mistura no forno. <br>
11 - Aguardar até ficar pronto. <br>
12 - Retirar do forno. <br>
13 - Desenformar o bolo e colocá-lo em um prato ou outro recipiente. <br>
14 - Cortar o bolo. <br>
15 - Comer o delicioso bolo :D
